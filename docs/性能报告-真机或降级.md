# 性能报告——真机 GPU 实测（阶段 A1 · 2026-10-11）

## 测法

上一轮 100 元件"运行中 7fps"出自 **headless SwiftShader 软渲染**（无 GPU）。本轮改用
Playwright **有头模式**（Chrome for Testing 151，真机 GPU，viewport 1560×980），同一
元件配方（物块+小球+弹簧+绳+传感器 五件组 × N + 地面），静置与运行各采样 3 秒 rAF。

## 数据

| 场景 | 元件数 | 静置 fps | 运行中 fps | 达标（≥30） |
|---|---|---|---|---|
| 常规课堂场景 | 31 | 165（vsync 顶格） | 165 | ✅ |
| 中型 | 51 | 165 | 162 | ✅ |
| 极端大场景 | 101 | 165 | **61** | ✅ |

## 结论与"学生实际使用预期"

- **学生实际使用预期：常规搭建（≤50 元件）满帧 60fps（浏览器 vsync 上限，实测 165 为
  未开垂直同步的 rAF 顶格）；100 元件极端堆料 61fps，仍两倍于 30fps 目标。**
- headless 7fps vs 真机 61fps ≈ 1:9——后续 CI 里的 headless 帧率仅作回归对比基线，不作
  用户体验结论（已写入 monitoring.md 口径）。
- 渲染层（three.js 100+ mesh）静置 165fps 证明非瓶颈；运行中降幅来自物理帧驱动的场景
  同步（30fps 引擎推送 + 101 元件位姿更新），属正常。
