### 2.1 单页壳（0.5d）

- **风险**：布局窗口尺寸——现有 `.bottom` 固定高度，需弹性布局

### 2.2 四面板迁移（1.5d + 0.2d OCR 缓冲）

### 2.3 保存合一 + 深链（0.5d）

- **依赖**：2.1（工具栏容器）
- **风险**：后端场景 API 的认证与错误处理路径

### 2.4 路由/导航清理（0.3d）
