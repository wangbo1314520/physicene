# 审查结论库

同类问题不重复问 Harness——命中即按既定结论处理。每次 Harness 给出新结论 → 追加。

## 半虚报
判据：commit 声称 vs diff 实际
结论：diff 没有 = 未做，不管 commit 怎么写
首次：假收紧（0.15 标签 vs 代码 0.15）
再犯：dampingRatio（参数到 Java 无消费）、region_params（catalog diff 无 L/W）

## 静默丢弃
判据：写了但没接线
结论：必须显式拒绝，不许静默
首次：heater（notes 从未上屏）
再犯：pkg.notes 通道、NO_BODY 检测器（SensorElement 写好但前端丢弃）

## 直算掩盖断链
判据：力/值用直算公式而电路/通道另有实现——断链不可见
结论：消费方必须真读通道（rod 读电路电流为正确范式）；直算=物理在、链路死
首次：coil F=−B²w²v/R 绕过电路（src_coil 硬编码 id 断链长期未暴露）

## 门禁生效性
判据：门禁代码存在 ≠ 门禁生效
结论：构造验证必须跑在部署路径上；路径错=恒过=从未生效
首次：env_gate parent.parent 指 frontend/java-backend（不存在→空转，第 4 次假重启漏抓）
再犯：v2 NO_BODY 分类首版对 spread 写法提取空集（空转检查）

## 覆盖率口径
判据：完整覆盖公式 65 − 1(69) − 降级 − 申改
结论：降级与申改均不计完整；历史数字须能对账（57/60/62 各有成因）
首次：P4 批3 宽口径把申改计入完整（60），后续误报 62

## 小活不当轮做
判据：估时 ≤1d 且判据明确的遗留项
结论：当轮做掉，不拆到下批——"上线前加新功能=加风险"不适用于接线级小活
首次：photogate 三件原列 P6（0.7d，两件接线级）——审查指出后当轮落地

## 时序量化
判据：断言量为时间差/峰值类连续量时，采样层级决定误差
结论：时间差断言必须子步级检测；max-y 类断言的采样轮询要够密（200ms→50ms）；术语用"消耗比例"
首次：pendulum halfPeriod 帧级 1/60s（2% 误差）；卡26 max-y 轮询相位吃掉容差 73%

## 测试文本匹配
判据：has_text 是子串匹配
结论：文本匹配必须精确（"速度传感器"撞"加速度传感器"）；lint 规则静态禁
首次：free-build 器材 E2E 两传感器同值复跑才暴露

## 迁移全扫
判据：页面迁移（路由/结构变更）时只修了"当轮跑的脚本"
结论：lint-migration 活路由清单=迁移 checklist；没跑过的脚本=死脚本（checkpoint-sweep 每测点全跑，要么跑要么删）
首次：stress/reconnect 停在 /exp 旧路由；再犯：f13 E3+计数 17

## 存在≠已初始化
判据：E2E 只 wait_for_selector / count()>0（元素存在），不验元素被正确初始化（尺寸/渲染/绑定）
结论：canvas 类元素必须验"尺寸非默认 + 有渲染内容"；v-if 卸载重建的新元素选择器照样命中——静默失效零报错
首次：实验台 canvas（renderer 绑定旧元素，切回后新 canvas 300×150 空白，F1.2/F1.3/lab-check 全绿漏过）
