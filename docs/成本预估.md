# 成本预估（阶段 A3 · 2026-10-11）

## 单次调用（实测口径）

- 输入 ≈ 1000-1500 token（意图分流系统提示 ~600 字 + RAG 3 片段 × 200 字 + 问题）
- 输出 ≈ 250-750 token（回复 250-747 字实测；完整讲解 600-900）
- **合计 1.5-2.2k token/次**（中文约 1 token/字）

## ¥10-60/天 6 倍差的两个端点假设（5000 次/天）

| | 低值 ¥10/天 | 高值 ¥60/天 |
|---|---|---|
| 学生数 × 频次 | 100 学生 × 50 次 = 5000 次 | 同左（次数相同） |
| 单次 token | **1.5k**（多为短问答：概念/验证类，输出 250 字） | **2.2k**（多为完整讲解：AI 深讲/直接讲解，输出 750 字） |
| 单价假设 | 输入 ¥1/M + 输出 ¥2/M（历史低价档） | 输入 ¥4/M + 输出 ¥16/M（历史高价档） |
| 计算 | 7.5M×1 + 2.5M×2 ≈ ¥12.5→取整 ¥10 量级 | 7.5M×4 + 2.5M×16 ≈ ¥70→按实际混合 ¥60 量级 |

即：**次数固定时，6 倍差来自"问什么"（短问答 vs 完整讲题）×"当日牌价"两变量**。

## 月/年上限

| 口径 | 计算 | 金额 |
|---|---|---|
| **月成本上限** | 30 × 高值 | **≤ ¥1,800/月** |
| 年成本 | × 12 | **≤ ¥21,600/年** |
| 典型教学月（按低值+周末折减 ≈ 20 天有效） | 20 × ¥10 | ≈ ¥200/月 |

**硬上限已由限流锁定**（A2 落地）：每学生每日 100 次 → 100 学生极端全满 =
10,000 次/天 ≤ ¥120/天 → **月 ≤ ¥3,600（绝对上限，实际不可能触达——教学用量
约为其 1/10-1/5）**。

## 复算公式（牌价变动时）

`日成本 = 次数 × (输入token×输入单价 + 输出token×输出单价)`，单价以 DeepSeek 官网当日为准。
