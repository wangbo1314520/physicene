## 1. 总体架构

### 1.1 目标形态

```
/exp  统一几何搭建台（BuilderView）
 ├─ 左：元件面板（六大类 92 个几何元件，catalog v2）
 ├─ 中：几何画布（three.js，米制世界坐标，2D/2.5D/3D 视角）
 ├─ 右：属性面板 + 引擎分析卡（EngineAnalyzer：本场景需要哪些引擎、耦合链、警告）
 ├─ 下：运行控制（时间轴/关键事件/回放/图表）+ 多物理场数据面板 + AI 助手（BuilderAi）
 └─ 运行
    ├─ 联合运行（含刚体的场景）→ Java 统一仿真（WS 30fps 帧 + 多物理场通道）
    │    ├─ 刚体力学：dyn4j World（现有 SimulationInstance 扩展）
    │    ├─ 电磁场：ElementBehavior 力源（现有）+ 粒子积分（现有 point_charge 行为）
    │    ├─ 电路：MNA 移植到 Java（physics.circuit，新增）
    │    ├─ 热学：GasCell（新增，理想气体/多方过程，活塞耦合）
    │    └─ CouplingOrchestrator（新增，耦合调度）
    └─ 单域运行（纯光学/纯近代/纯热学静态/纯电路编辑）→ 前端 TS 引擎
         ├─ 光学：RayTraceEngine（现有 prism 折射核心抽出的光线追踪，扩展）
         ├─ 近代：ModernModels（现有 mod1/mod2 的参数化模型）

         └─ 电路编辑：CircuitEditor + TS MNA（现有，交互式）
```

## 2. 统一元件模型

### 2.1 前端 `src/builder/model/Element.ts`（新增，~260 行）

```ts
/** 统一几何元件：基于 /lab PhysicsElementInput 扩展 */
export interface GeoElement {
  id: string
  type: GeoType                      // §2.3 的 37 种几何类型 + 28 种装置类型
  position: { x: number; y: number } // 米制世界坐标（画布即物理世界，比例尺固定 40 px/m）
  angle: number                      // rad，绕元件原点
  shape: ShapeDef                    // 几何（装置类型为包围盒示意）
  params: Record<string, number>     // 类型参数（质量/摩擦/带速/B/…，规格在 catalog）
  anchors?: AnchorState[]            // 实例锚点世界坐标（由类型模板 + transform 计算）
  initialState?: { velocity?: { x: number; y: number }; angularVelocity?: number; bullet?: boolean }
  isFixed: boolean
  role: 'body'|'constraint'|'field'|'circuit'|'thermal'|'optic'|'device'|'detector'|'display'
  circuitRef?: { terminalIds: string[] }     // 耦合元件的电路端子（如导体棒两端）
  thermalRef?: { cellId: string }            // 活塞归属气室
  display?: { label?: string; color?: string; showTrail?: boolean; showVectors?: boolean }
  links: { toId: string; kind: 'rope'|'rod'|'spring'|'wire'|'pulley-rope'; anchorA: string; anchorB: string }[]
}

export type ShapeDef =
  | { kind: 'rect'; w: number; h: number }
  | { kind: 'circle'; r: number }
  | { kind: 'polygon'; points: { x: number; y: number }[] }                          // 局部坐标 CCW
  | { kind: 'arc'; r: number; a0: number; a1: number; thickness: number; side: 'inner'|'outer'|'both' }
  | { kind: 'capsule'; length: number; radius: number }                              // 传送带
  | { kind: 'point' }                                                                  // 锚点类（滑轮锚、悬点）
  | { kind: 'device'; w: number; h: number }                                           // 装置包围盒

export interface AnchorState { id: string; kind: AnchorKind; world: { x: number; y: number }; tangentDir?: { x: number; y: number } }
export type AnchorKind = 'endpoint' | 'surfaceEnd' | 'tangentPoint' | 'terminal' | 'attachPoint' | 'apex'
```

**数据结构依据**：`GeoElement` 字段 = 现 `PhysicsElementInput`（`frontend/src/composables/useSimulationSocket.ts:14`）全量字段 + `shape/anchors/role/refs/links`；旧字段 `scale/properties` 合并进 `shape/params`，Java 侧由 `GeoElementMapper` 反向生成 `PhysicalProperties`（保持现有 `physics/model/PhysicsElement.java` 兼容，教材层 `/exp/:id` 与旧记录不受影响）。

## 3. Java 侧新增（阶段一：刚体扩展；阶段二：耦合）

### 3.1 传送带 `BeltElement.java`（新增，~120 行）

- **几何**：`Geometry.createCapsule(length, 2r)`（已核验存在于 dyn4j 5.0.2）静态体，上表面 y=+r。
- **物理**：注册 `BeltContactListener implements ContactListener<Body>`（dyn4j `world.addListener`），在 `preSolve(ContactCollisionData, Contact)` 回调中对任一 fixture 属于 belt 的 `data.getContactConstraint().setTangentSpeed(vBelt)`（**已核验**：`ContactConstraint.setTangentSpeed(double)` 存在，dyn4j 官方语义即传送带表面速度）；方向 = 带体局部 +x 旋转 `angle` 后的世界向切向投影。
- **参数**：`vBelt ∈ [−8, 8] m/s`、`length ∈ [1,12]`、`r=0.15`、`μ ∈ [0,1]`。
- **关键事件**：`belt_common_speed`（见 §3.6）。

### 3.2 圆轨道 `LoopTrackElement.java`（新增，~140 行）

- **几何**：按 `a0..a1, R, thickness, side` 生成弧上点列（分段角 5°，N=⌈(a1−a0)/5°⌉），`Geometry.createLinks(points, false)`（**已核验**存在，Link 形状专为链状轨道设计，相邻段共享端点、无幽灵凸起）生成静态 fixture 链；`side='both'`（管道）时生成 R±t/2 双链。
- **单侧接触语义**：内轨（球在轨内）与外轨（球在轨外）由同一条链自然成立——dyn4j 接触法线朝向穿透方向，无需单面材质。
- **参数**：`R ∈ [0.3,3]`、`a0/a1`、`side`、`μ=0`（题目口径光滑）。
- **关键事件**：`apex_pass`（过顶）、`detach`（接触法向力归零，见 §3.6）。

### 3.3 关节四件 `physics/joint/`（新增 1 类 + 既有工厂，~200 行）

全部基于 dyn4j `DistanceJoint`（**已核验**其实现 `LinearLimitsJoint + LinearSpringJoint`，含 `setUpperLimitEnabled/setSpringEnabled/setSpringStiffness/setSpringDampingRatio`）：

| 元件 | dyn4j 配置（精确） | 说明 |
|:--|:--|:--|
| `rope`（绳） | `new DistanceJoint<>(b1,b2,p1,p2)`；`setUpperLimit(L); setUpperLimitEnabled(true); setLowerLimitEnabled(false); setSpringEnabled(false)` | 只限最大长：松弛自由、绷紧即刚——绳的正确语义 |
| `rod`（杆） | 同上构造；limits 关闭、spring 关闭，`setRestDistance(L)` | 刚性定长 |
| `spring`（弹簧） | `setSpringEnabled(true); setSpringStiffness(k); setSpringDampingRatio(c/(2√(k·m_red)))`，limits 关闭 | 软约束；m_red 为两体折合质量，damping 由元件参数 `ζ ∈[0,1]` 换算 |
| `pulley`（滑轮） | **绳段图建模**：定滑轮 = 两段 `rope`（公共端锚在滑轮点）；动滑轮 = 生成 1 个隐藏小质量体 + 3 段 `rope`（上锚→滑轮体、滑轮体两端→两负载） | 拉力相等、`a_B=a_A/2` 由绳长约束自动成立；滑轮渲染旋转为装饰（three.js 动画，无物理自由度）。**不使用** `PulleyJoint`（其滑轮锚世界固定，表达不了动滑轮）。`PulleyJoint` 保留给"天花板双定滑轮"花式连接 |

### 4.2 锚点吸附算法（`model/snap.ts`，精确规格）

拖动中实时预览、松手提交；阈值 `δ=0.35 m`（世界单位，随缩放不变）。

```
1. 候选：拖动元件 A 的每个锚点 a，与所有其他元件 B 的锚点 b，
   若 (a.kind ∈ b.accepts ∨ b.kind ∈ a.accepts) 且 |a_world−b_world| < δ → 生成提案
2. 每提案计算刚体变换：
   translate: dθ=0, T = b_world − a_world
   tangent(仅 loop.entry / belt.surfaceEnd 等 align:tangent 锚)：
     dθ = wrapToPi(dirAngle(b.tangentDir) − dirAngle(a.tangentDir))，再按旋转后的 a_world 重算 T
3. 排序键（元组比较）：(|a−b| 距离, tangent 优先级 0 < translate 1, 锚点模板序号)
   取最小者高亮；Enter/双击或「自动吸附」开关注入 T（position+=T, angle+=dθ），可 Ctrl+Z 撤销
4. 冲突：一提案成立后其余锚点提案作废（一次只做一处吸附）；吸附后仍可继续拖走
```
