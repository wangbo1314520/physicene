### 关键技术决策与踩坑

- **dyn4j 5.x 包结构与 4.x 不同**：World 在 `org.dyn4j.world`（非 dynamics）；监听器注册用
  `addCollisionListener`（非 addListener）；Vector2 模长是 `getMagnitude()`（非 magnitude()）。
  通过 jar 反编译（javap）逐个探明后编码，一次编译通过率大幅提升。
- **step(1) 语义**：实测确认每调用一次推进一个 1/60s 步，与契约 timestep 一致（自由落体 60 帧=1s 验证）。
- **碰撞去重**：碰撞持续期 ManifoldCollisionData 每步回调，用 pair Set 去重只报首次。
- **前端 TS 7 不兼容**：pnpm 默认装了 TypeScript 7（原生重写版），vue-tsc 报
  `ERR_PACKAGE_PATH_NOT_EXPORTED`；锁定 `typescript@~5.9.0` 解决。
- **E2E 时序**：帧只在运行中推送，测试脚本必须"run 后立刻连 WS"（分两次 curl 会错过整场仿真）。
