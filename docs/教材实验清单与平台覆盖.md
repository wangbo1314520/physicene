### 物理原理上无法模拟的（超出 2D 质点动力学范畴，需真实器材或专用仿真）

| 类别 | 实验 | 缺失能力 |
|:--|:--|:--|
| 电路 | 电阻率测量、多用电表、电动势与内阻 | 需电路仿真（欧姆定律网络求解） |
| 振动 | 单摆测 g、弹簧振子、共振 | 需绳/弹簧约束元件（v1 无约束系统） |
| 机械波 | 绳波、水波、声干涉 | 需介质波动方程 |
| 光学 | 双缝干涉、全反射、偏振 | 需波动光学 |
| 热学 | 油膜法、气体定律、压缩做功 | 需热力学/统计模型 |
| 电磁感应 | 楞次定律、自感、交变电流 | 需磁通变化/电路耦合 |
| 原子 | 光电效应、天然放射 | 需量子/核物理模型 |

> 答辩口径：平台定位是"高中物理**力学与场**实验的 AI Agent 仿真"，光学/热学/电路明确列入 v2 演进路线（SRS §8.2 亦有规划）。
