## 4. 备份（方案 B·自建 MySQL，2026-10-02 审查裁定）

**定期自动备份（每日 03:00，保留 7 天）**——防"改错"之外的磁盘坏/误删/被黑：

```bash
# Linux（cron）：crontab -e 加入
0 3 * * * MYSQL_PWD=$DB_PWD /opt/physicene/scripts/backup-db.sh /var/backups/physicene >> /var/backups/physicene/backup.log 2>&1

# Windows（计划任务，本机已注册并触发验证 LastTaskResult=0）：
powershell -Command "Register-ScheduledTask -TaskName 'PhysiScene-DB-DailyBackup' -Action (New-ScheduledTaskAction -Execute 'E:\Program\physicene\scriptsackup-db-task.cmd') -Trigger (New-ScheduledTaskTrigger -Daily -At 03:00) -Force"
```
脚本：`scripts/backup-db.sh`（Linux）/ `scripts/backup-db.ps1`+`backup-db-task.cmd`（Windows）——
含 gzip + 完整性自检（gunzip -t + Dump completed 尾标记）+ 7 天保留窗口自动清理。已实测 2.2–2.6M/份。

## 5. 回滚（可复制命令）

- 应用：回退 jar + 重启（无状态）
- schema：Flyway 社区版无 down-migration——回滚=还原备份 + 回退 jar。

**回滚前必须先做当刻快照**（不是"应该备份"，是执行这条）：

```bash
# ① 回滚前快照（保留事故现场，防"回滚本身失误"）
MYSQL_PWD=$DB_PWD mysqldump -uroot --single-transaction --routines --triggers --databases physicene   | gzip > /var/backups/physicene/physicene-rollback-$(date +%Y%m%d-%H%M%S).sql.gz

# ② 从最近备份还原（文件名取 backups 目录实际时间戳）
gunzip < /var/backups/physicene/physicene-YYYYMMDD-HHMMSS.sql.gz | mysql -uroot -p

# ③ 回退应用 jar 并重启；④ 验证：mysql -e "SELECT version FROM physicene.flyway_schema_history" + /actuator/health
```
