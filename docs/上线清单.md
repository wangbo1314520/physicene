# 上线清单（测点 6 · 2026-10-02）

适用版本：feature/exp-b8 @ 测点 6。前一版见《上线评审-v3.1-高考竞赛层.md》（F 系列口径）；
本清单为 **Flyway 化后的部署权威版**——取代其中手动建库步骤。

## 1. 环境要求

| 组件 | 版本（本机验证口径） | 用途 |
|---|---|---|
| JDK | 17.0.2 | 后端 |
| MySQL | 8.0.37 | 数据（**无需手工建库**——JDBC `createDatabaseIfNotExist=true` + Flyway） |
| Node/pnpm | 按 frontend/package.json engines | 前端构建 |
| Python | 3.12.x | E2E/巡检脚本 |
| Maven | 3.9.9 | 后端构建 |

## 2. 部署步骤（全新环境）

```
1. 后端：cd java-backend && mvn -q package -DskipTests
   启动：java -jar target/*.jar
   （首次启动自动完成：建库 → Flyway V1 建 14 表 → V2 种子 admin/demo/OCR → Hibernate validate 校验）
2. 前端：cd frontend && pnpm install && pnpm build → dist/ 交静态服务
3. 冒烟：GET /actuator/health=200；POST /api/auth/login demo=200；
   打开前端 → /lab 自由搭建可运行模板
```

**既有库升级**：直接启动——`baseline-on-migrate@2` 自动打基线（V1/V2 跳过），V3+ 统一生效。
**schema 演进**：只加 `db/migration/V3__xxx.sql`（禁止手 DDL——P5a 批 1 手动 CREATE TABLE 次生事故的制度化禁令）。`scripts/init-db.sql` 已退役（保留作物证）。

## 3. 配置与安全

- `application.properties`：`ddl-auto=validate`（只校验不迁移，schema 归 Flyway）
- 密钥：DEEPSEEK_API_KEY 只在 `.env`（**不入库不打印**）；DB 凭据走环境（本机 root/123456 仅限本地开发）
- ai-tutor 依赖 python-ai-service(8000)；未启动时教学讲解走内置回退（E2E 已断言回退行为）
- admin 初密 admin123（V2 种子）——**上线后立即改密**

## 4. 回滚

- 应用：回退 jar + 重启（无状态）
- schema：Flyway 社区版无 down-migration——回滚=还原 DB 备份 + 回退 jar；
  变更前必做 `mysqldump` 快照（运维脚本化，测点 6 起列为变更前置）

## 6. 已知限制（如实清单）

- 地面系平台（frame=1）静置承载不传速（放置即警告，辨析场景专用）
- 物块跨导入段端点会微抖 ~2s 后自止（放置即警告）
- accel_sensor 为最小二乘差分（7.8% 级）；光电门时刻为帧级采样（±1 帧）
- ai-tutor 真 AI 路径需 python-ai-service；DDL 漂移检测依赖 Flyway 版本纪律（V3+ 递增）
