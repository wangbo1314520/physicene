## 2. 数据模型（MySQL 扩展 DDL 草案）

```sql
-- 实验会话表（完美版持久化核心）
CREATE TABLE IF NOT EXISTS experiment_session (
    id              BIGINT NOT NULL AUTO_INCREMENT,
    student_id      BIGINT NOT NULL,
    experiment_id   VARCHAR(64) NOT NULL COMMENT '实验注册键，如 bx1-timer-tape-1',
    status          ENUM('draft','submitted') NOT NULL DEFAULT 'draft',
    step_state      JSON NULL COMMENT '步骤状态机快照：{currentStep, completed[], scores{}}',
    raw_data        JSON NULL COMMENT '原始读数记录（表格行/纸带点/电路快照）',
    processed_data  JSON NULL COMMENT '处理后数据（描点坐标/拟合结果/图像配置）',
    conclusion      TEXT NULL COMMENT '学生结论',
    ai_feedback     TEXT NULL COMMENT 'AI 助教反馈',
    version         INT NOT NULL DEFAULT 1 COMMENT '乐观锁（多端同步）',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_student_exp (student_id, experiment_id),
    KEY idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 3. API 契约（/api/experiments/*）

| 方法 | 路径 | 说明 |
|:--|:--|:--|
| POST | `/api/experiments/sessions` | 开始/恢复实验：{experimentId} → 会话（有草稿则续做） |
| PUT | `/api/experiments/sessions/{id}` | 自动保存：{stepState, rawData, processedData, conclusion, version}；409=版本冲突（多端） |
| POST | `/api/experiments/sessions/{id}/submit` | 提交：锁定 → 生成 Report 关联 + 通知 AI 生成反馈 |
| GET | `/api/experiments/sessions?experimentId=&status=` | 我的实验列表（断点续做入口） |
| GET | `/api/experiments/sessions/class?experimentId=` | 教师端：班级提交统计（教师角色校验） |

错误码沿用 §6.4 体系；JWT 鉴权同现有拦截器。

## 4. 三大引擎组件规格

### 4.1 坐标纸作图 GraphPaper（完美版清单逐条落地）

- 网格坐标纸，坐标轴名称/单位/量程可配置，轴缩放
- 手动描点（点击落点）、拖拽移动、右键/点选删除；实时显示坐标提示
- 最小二乘直线拟合：斜率 k、截距 b、R²、各点残差列表；可强制过原点（b=0，纸带/胡克常用）
- 误差棒（可选列 σ）、异常点一键标记（高亮+拟合自动剔除开关）
- 模式切换：自动画图（数据表变更即时重绘）/ 手动描点（评分用）
- 与 DataTable 联动：表格行 ↔ 图上点双向高亮
- 导出：PNG（toDataURL）+ 数据 CSV；提交时整图存 processed_data

### 4.2 电路引擎 CircuitBoard

- 元件库：电池(E,r)、电阻、开关、电流表/电压表（量程/内阻）、滑动变阻器（分压/限流）、电容、电感、二极管、导线
- 自由搭建：SVG 画布拖元件、引脚吸附连线、节点自动归并；固定模板模式（题目电路锁定布局）
- 求解：DC 节点电压法（含内阻/电表负载效应）→ AC 相量法（复阻抗）→ RC/RL 瞬态（RK 数值解，充放电曲线）
- 安全检测：短路（0Ω 回路报警）、断路（孤岛节点）、极性接反提示、量程超限打表
- 智能判分：与实验目标电路比对（拓扑+参数），错误定位到元件级提示

### 4.3 3D 场力引擎 Scene3D

- Three.js + OrbitControls：左键旋转/右键平移/滚轮缩放；触屏单指旋转/双指缩放平移（OrbitControls 原生）；触控笔=指针事件
- 预设视角按钮（正视/侧视/俯视/自由）、重置、自动旋转、剖面视图（clippingPlane）、遮挡半透明
- Integrator（RK4）：`step(pos, vel) → acc` 接口，各实验只写加速度函数
  - 洛伦兹力：a = q(E + v×B)/m；α散射：a = Kq₁q₂/r² 方向；布朗：随机冲量
- 3D 渲染件：矢量箭头（长度∝大小）、B 场 ⊙⊗ 阵列（沿面排布）、线圈螺线管模型、检流计 2D 仪表联动

## 5. 实验模块接口（注册表契约）

```ts
interface ExperimentModule {
  id: string                // 'bx1-timer-tape-1'
  book: string              // '必修第一册'
  chapter: string           // '第二章 匀变速直线运动'
  dimension: '2D' | '2.5D' | '3D'
  name: string
  summary: string
  component: () => Promise<Component>   // 懒加载
  steps: ExperimentStep[]
}
interface ExperimentStep {
  id: string
  title: string             // '调节斜面倾角'
  hint: string              // 操作提示（AI 助教同源引用）
  check?: (state) => 'pass' | 'fail'   // 条件触发推进（考试模式强制）
  errorHints?: Record<string, string>  // 纠错引导
  scoreWeight?: number      // 过程性评价权重
}
```

步骤引擎：状态机（引导模式=提示全开+软推进；自由模式=无检查；考试模式=硬检查+计时+评分）。AI 助教上下文注入 `{experimentId, currentStep, rawData}`——按步骤提示、不跳步、不直接给答案（prompt 约束）。
