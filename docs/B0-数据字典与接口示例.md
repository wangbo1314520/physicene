# 实验库 B0 数据字典与接口示例

## experiment_session 表

| 字段 | 类型 | 说明 |
|:--|:--|:--|
| id | BIGINT PK AI | 会话 ID |
| student_id | BIGINT NOT NULL | 学生（FK 逻辑关联 user.id） |
| experiment_id | VARCHAR(64) NOT NULL | 实验注册键（如 bx3-coulomb-repulsion） |
| status | ENUM('draft','submitted') | 草稿=断点续做；提交=锁定 |
| step_state | JSON | `{current:int, completed:[stepId], records:{stepId:data}, mode:guided\|free\|exam}` |
| raw_data | JSON | 原始读数（B0：仿真摘要 {totalDuration, endReason, keyEvents, velocityExtremes, kineticEnergy, frames}；B1 起坐标纸数据） |
| processed_data | JSON | 处理数据（B1 起描点/拟合/图像配置） |
| conclusion | TEXT | 学生结论 |
| ai_feedback | TEXT | AI 反馈（B7 回填） |
| version | INT | JPA @Version 乐观锁（并发 409） |
| created_at / updated_at | DATETIME | |

索引：idx_student_exp(student_id,experiment_id)、idx_student_status、idx_exp_status、idx_version

## report 表扩展（V2）

- `record_id` 改可空（第六周仿真记录 或 实验会话 二选一）
- 新增 `session_id BIGINT NULL` + idx_session_id：实验提交挂接
- content JSON（实验会话来源）：`{experimentType:"exp-session", sessionId, experimentId, studentId, conclusion, rawData, stepState, submittedAt}`

## API 示例（JWT: Authorization Bearer）

```bash
# ① 开始实验（有草稿自动断点续做）
curl -X POST http://localhost:8080/api/experiments/sessions \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"experimentId":"bx3-coulomb-repulsion"}'
# → {"code":0,"data":{"id":5,"status":"draft","resumed":false,"stepState":{...},"version":1}}

# ② 自动保存（2s 防抖；并发版本冲突 → HTTP 409 / code=1005）
curl -X PUT http://localhost:8080/api/experiments/sessions/5 \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"stepState":{"current":2,"completed":["read","run"],"records":{},"mode":"guided"},"conclusion":"..."}'
# → {"code":0,"data":{... "version":3}}

# ③ 提交（锁定 + 生成 Report 挂接；重复提交 code=1005 幂等拦截）
curl -X POST http://localhost:8080/api/experiments/sessions/5/submit \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"conclusion":"同种电荷相互排斥"}'
# → {"code":0,"data":{"status":"submitted","reportId":12}}

# ④ 我的实验
curl "http://localhost:8080/api/experiments/sessions?status=submitted&page=1&size=20" \
  -H "Authorization: Bearer $TOKEN"

# ⑤ 教师统计（仅 teacher/admin；学生 → code=1003）
curl "http://localhost:8080/api/experiments/sessions/class?experimentId=bx3-coulomb-repulsion" \
  -H "Authorization: Bearer $TEACHER_TOKEN"
# → {"code":0,"data":{"submittedCount":3,"draftCount":1,"recent":[...]}}
```

## 错误码（沿用 SRS §6.4）

| 场景 | code | HTTP |
|:--|:--:|:--:|
| 并发保存冲突/已提交再存/重复提交 | 1005 | 409 |
| 会话不存在 | 1004 | 404 |
| 访问他人会话 / 学生调教师统计 | 1003 | 403 |
| 未登录 | 1002 | 401 |
