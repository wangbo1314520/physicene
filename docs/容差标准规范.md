# 容差标准规范（P4 批 2 审查令 · 制度化）

## 原则

**容差按实测标定，禁止按不确定给宽。**

## 三类容差来源

### 1. 数值积分误差（dt 收敛类）
- **依据**：ProjectileDtvTest 型对比——substeps 加倍，偏差应减半（O(dt²) 收敛）
- **标定**：dt=1/120 时的偏差 × 3-4 倍余量
- **典型值**：1-5%（如卡 26 抛体 maxY dt=1/120 偏差 1.2% → tol=5%）
- **验证方法**：跑 substeps=2 和 substeps=4，确认偏差减半

### 2. 物理简化误差（模型近似类）
- **依据**：写清简化假设（如"Coulomb 摩擦耗散 vs 理想静摩擦滚动"）
- **标定**：Java 诊断测试参数扫描（如 RollerDiagnosticTest mu=0→0.5）
- **典型值**：8-12%（如卡 69 刚体滚子 mu=0 时 9% 偏差 → tol=12%）
- **必须标注**：简化假设名称 + 诊断测试名

### 3. 测量噪声（运行间变化类）
- **依据**：同参数跑 5 次，取 σ
- **标定**：σ × 3 倍 + 数值误差
- **典型值**：0.2-1%（如卡 26 σ=0.23% → 已含在 5% 内）
- **验证方法**：5 次同参数，σ < 1% 视为 deterministic

## 禁止

- ❌ "不确定所以给宽"（如卡 38 原 15% 但实测偏差 0.5%）
- ❌ "改理论让断言过"（如卡 25 原 1.914 标定因子）
- ❌ 无依据的 15% / 20% / 30%

## 容差审批流程

1. 先跑实测 → 得到偏差 d
2. 确认偏差来源（数值/简化/噪声）
3. tol = d × 3-4 倍（数值类）或 d + 安全余量（简化类）
4. 在 label 中标注来源和依据
5. 如果 d > 10%：需出诊断测试证明来源

## 本规范适用范围

全部 builder 模板 criticalChecks + 全部 E2E 断言。

## 加严条款（P4 批 2 整改审查令）

### 物理简化类容差——必须有解析估计

**原规范**（已废）："物理简化 8-12%，诊断测试参数扫描"
**加严后**：
1. 物理简化的容差必须有**解析估计**——不能"实测 12% 所以给 12%"
2. 容差 = **解析估计值 × 1.5 倍**（不是实测值 × 1.3 倍）
3. 没有解析估计的，不许声称"这是物理简化"——必须归为"未解决偏差"

**解析估计的定义**：从物理模型推导出的误差上界表达式（含参数），非经验拟合。

示例（合格——有解析推导）：
- 26 卡 Euler 积分：误差 ≈ ½·g·dt·t_rise（上升段累积速度误差）
  = ½×9.8×(1/120)×0.51 = 0.021m = 1.2% of 1.776m ✓（与实测 1.18% 吻合）
  注意：不是 O(g·dt²/8)（那只是单步误差 0.085mm——差两个量级）

示例（不合格——已修正）：
- 69 卡"9% 减速"：原称"解析来源=I=k·mR² 等效减速"——**错误**
  实际 1−1/√(1+k) 对 k=0.5 是 18.4%，不是 9%
  9% 来源 = 实测 4.949/5.422 = 经验标定（非解析推导）
  → 归"经验标定"类（见下）

## 第四类：经验标定（P4 批 2 新增）

某些模型行为无法解析推导（如 dyn4j 接触几何导致的固有角速度），只能实测标定。

**标定方法**：
1. Java 诊断测试参数扫描（如 RollerDiagnosticTest mu=0→0.5）
2. 取稳定比率作为标定因子
3. **必须在 label 中标注"经验标定"（非"解析推导"）**
4. 容差 = 标定值的运行间变化 × 3 倍（不是偏差 × 1.5 倍——因为标定因子已内含偏差）

**与物理简化的区别**：
- 物理简化：有解析估计公式（可以推导）→ 容差 = 解析估计 × 1.5
- 经验标定：无解析估计（只能实测）→ 容差 = 运行间 σ × 3（标定因子吸收了系统偏差）
