# 仿真实验开发优先级与最佳维度规划

> 判定口径：第一阶段（核心必做 22 个）——高考/教材核心，数据读取、图像处理、操作规范强，仿真收益高；第二阶段（有必要 18 个）——开发强度较高或更适合后置；第三阶段（不建议 12 个）——真实实验易做、视频/动画/模型已足够，不做完整仿真（本规划不含）。
>
> 唯一维度口径：**纯2D**（平面交互/图像/数据）、**纯2.5D**（2D 物理 + 立体渲染）、**纯3D**（完整三维空间关系）。
>
> 日期：2026-09-14

---

## 汇总

| 阶段 | 总数 | 纯2D | 纯2.5D | 纯3D |
|:--|:--:|:--:|:--:|:--:|
| 第一阶段 | 22 | 10 | 12 | 0 |
| 第二阶段 | 18 | 6 | 3 | 9 |
| **合计** | **40** | **16** | **15** | **9** |

**一句话总结**：
- 第一阶段：纯2D 和纯2.5D 为主，完全不用3D。
- 第二阶段：纯3D 为核心，必须重点开发 9 个纯3D 实验。

## 附：与 PhysiScene 平台现状的对照（讨论稿，2026-09-14）

> 平台现状：dyn4j 2D 物理引擎 + Three.js 渲染（正视图 / 等距 2.5D 双视角），已覆盖 18 个"场景搭建型"演示实验。

**平台能力映射**：

| 维度需求 | 平台现状 | 缺口 |
|:--|:--|:--|
| 纯2.5D（力学/场实验） | ✅ 已支持（dyn4j + Three.js），已覆盖动量/平抛/机械能/a-F-m/库仑/洛伦兹/α散射等 14 个 | 向心力、功与速度、弹簧、单摆需约束元件（绳/弹簧），可先用参数化组件替代 |
| 纯2D（纸带/数据/电路/光学） | ⚠️ 无专门组件 | 需新建：① 仪器面板框架（纸带/刻度尺/秒表/数据表/坐标纸）② 电路求解器（DC→AC）③ 光路/波场渲染组件 |
| 纯3D | ❌ 不支持（SRS 明确 v2 路线） | 需 3D 物理引擎与渲染重构，成本≈重做引擎层 |

## 最终确认单（2026-09-14 拍板 · 完美版，不做妥协版）

| 细节 | 确认结果 |
|:--|:--|
| 作图交互 | 手动描点 + 拖拽/移动/删除点 + 实时坐标 + 最小二乘拟合（斜率/截距/R²/残差）+ 误差棒 + 异常点标记 + 自动/手动模式切换 + 数据表联动 + 导出图像和数据。**必须做** |
| 电路搭建 | **自由拖元件搭电路**（电池/电阻/开关/电流表/电压表/滑动变阻器/电容/电感/二极管，自由连线与节点连接，量程选择，正负接反提示，短路/断路检测，智能判分与错误定位）+ 保留固定模板模式（引导/考试/演示）。**必须做** |
| 3D 交互 | 鼠标（左键旋转/右键平移/滚轮缩放）+ **触屏**（单指旋转/双指缩放平移）+ 触控笔 + 预设视角/重置/自动旋转 + 遮挡透明/剖面视图。**必须做** |
| 数据持久化 | **从一开始就存后端**：云端保存/自动保存/草稿/提交，含实验ID/学生ID/步骤/原始与处理数据/图像/结论/AI反馈/时间戳/版本；教师端查看批阅统计；与 Report 系统打通；导出 PDF/Excel/图片；断点续做、多端同步。**必须做** |
| 实验步骤条 | **实验平台的灵魂，必须做**：每实验步骤状态机（目标/提示/检查点/条件触发推进）、错误纠错引导、数据与步骤绑定、AI 助教按步骤提示不跳步不给答案、步骤评分与过程性评价、引导/自由/考试三模式 |
| 批次顺序 | **引擎先行 + 核心闭环 + 3D 核心前置 + 数据/AI 贯穿**（见下） |

### 修订后的批次计划（引擎先行版）

| 批次 | 内容 | 要点 |
|:--|:--|:--|
| B0 | 基础架构 | 实验库框架、**数据模型、步骤引擎接口、Report 接口预埋** |
| B1 | 2D 引擎 | 坐标纸作图组件（完美版全功能）、数据表、仪器面板 |
| B2 | 2.5D 引擎 | 复用 dyn4j + 约束元件（弹簧/单摆）、纸带采样 |
| B3 | 3D 引擎 | Three.js + OrbitControls（鼠标+触屏+触控笔）、场力积分器基类 |
| 阶段一 | 22 个核心实验 | 纸带×4、力学、电路×4、光学×2、热学×2、光电 |
| 阶段二 | 9 个纯 3D 核心 | 电磁感应×3、安培力、洛伦兹×2、变压器、布朗运动、α散射（前置开发，尽早验证 3D 引擎） |
| B6 | 数据持久化 + Report 联动 | 后端存储、教师端、导出 |
| B7 | AI 助教 + 步骤条完整化 | 步骤状态机全量、三模式、过程评价 |
| B8 | 拓展与替代 | 演示增强、第三阶段实验的视频/动画替代 |

> 排序理由：阶段一无 3D，3D 引擎无法尽早验证；阶段二 9 个纯 3D 是教学核心，后置风险大；数据持久化与 AI 应贯穿全程而非最后补。
