## 4. 全模板 isFixed 语义审计表（前置②交付）

| 元件类型 | Java 行为 | wire `fixed` 语义 | 结论 |
|:--|:--|:--|:--|
| wall / slope / e_field / b_field | 构造器 forceFixed(true)，与标志无关 | 恒固定 | 无风险 |
| loop_track / belt | 尊重标志，且 SceneValidator 强制 fixed=true（error 级） | 必须发 fixed | ✅ 已锁（JacksonBooleanNamingTest + validator） |
| cube / sphere / point_charge | AbstractMechanicalElement 尊重 data.isFixed() | 按标志 | ✅ 物理闸门 fixedBodiesStayPut（maxMove=0.0） |
| rope / rod / spring / pulley | 关节元件无刚体 | 无此语义 | 不适用 |

LabView/SimView 全部 17 处发送点已 rename 为 `fixed`（vue-tsc 编译期强制）。

**验收标准缺陷记录（永久）**：旧 /lab E2E 只断言"模板可载入+画布有元件+动画两帧不同+真实运行跑通"，不断言物理量——「正负点电荷电场线」模板 isFixed 被忽略、两电荷实际互相吸引运动达 5 周之久未被任何测试发现。教训入档：**模板级 E2E 必须含"应固定/应守恒量的数值断言"，动画≠物理正确**。builder-check.py 从设计起即按本条执行（每模板物理断言列于 §1/§2）。
