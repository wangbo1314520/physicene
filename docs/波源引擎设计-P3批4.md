### 覆盖范围：三卡共用一引擎

`wave.ts` 一个文件承载三个装置类型（与 dc-devices.ts 同构）：
- `wave_multi`（卡 58）：参数 λ/Δx₀/Δt/方向/n → 读数 Δx、v、T（两方向解集）
- `wave_graphs`（卡 59）：参数 A/λ/T/方向/x_P → 帧序列波动图采样 + 读数 v=λ/T、f=1/T、首峰 t、同侧法方向
- `wave_super`（卡 60）：参数 λ/d(源距)/P 坐标/相位 → 读数 PS₁、PS₂、Δr、k=Δr/λ、加强/减弱判定

### 与场景卡关系：当场收编（防第三处双实现）

opt1.ts（58/59）与 opt2.ts（60）的波动内联公式（v 通式、等温 pL 类比同行的 v=(nλ+Δx₀)/Δt、首峰 T(1/4+x_P/λ)、Δr 判据）在批 4 落地时**当场改 import wave.ts**——与批 2 thermal 收编同法。场景动画/画布保留，物理单一源。

### 单测独立来源

| 断言 | 独立来源 |
|---|---|
| v=λ/T | 方法独立：数值追踪波峰位置（t₁、t₂ 两时刻同波峰 x 坐标差/时间差）vs 闭式 |
| 首峰时刻 T(1/4+x_P/λ) | 方法独立：数值扫描 y(x_P,t) 的首个极大值时刻 vs 相位闭式 |
| 同侧法 | 教材图解法 vs 解析 ∂y/∂t 符号（两法） |
| 多解 v₁/v₂ 比值 | 教材例题形态：(nλ+Δx₀)/(nλ+λ−Δx₀)；并与场景卡 58 DOM 值（5.00/7.00 m/s）E2E 互证 |
| 干涉 Δr=kλ 加强 | 方法独立：数值叠加振幅 |y₁+y₂| 最大扫描 vs 光程差判据 |

## 事件 2：24 超重失重归属——建议归力学组

**归属理由（如实）**：物理上是 N=m(g±a) 纯力学，与 25 多过程同族；方案 §6.2 把它列入装置是粗分（"演示型场景"都塞了装置类）。**处理：从批 4 装置移出，group='力学'**。实现路径：力学组 TS 计算面（三阶段电梯：加速/匀速/减速的秤读数 N(t) 曲线帧序列）——不为它新建 Java 运动学平台（dyn4j 无恒加速运动学体，为一张卡加引擎能力成本不值，如实申报）。断言：加速段 N=M(g+a)（牛顿第二定律闭式）vs 引擎数值微分 dv/dt（两法）；教材规律锚：匀速段 N=Mg、完全失重 a=g 时 N=0（比值/边界锚）。
**装置定义口径（由此定清）**：装置组=电磁/热/光/近代的"单一参数化设备"；力学/几何类演示一律归力学模板组（几何搭建或力学计算面），杜绝力学卡再入装置组。
