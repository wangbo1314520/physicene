## 本轮补齐（3 新元件 + 2 扩展）

| 新增 | 用途 | 物理映射 |
|:--|:--|:--|
| vwall 竖直墙面 | 弹簧振子/绳摆/阿特伍德固定端 | Java wall 旋转 90°（H 参数）|
| anchor_point 悬挂锚点 | 天花板/支架点（滑轮、晾衣绳、绳摆）| 视觉+吸附锚点（绳/弹簧单端悬点机制既有）|
| lead_in 切线导入段 | 轨道入口平滑过渡 | Java wall 薄段（L 参数、可旋转）|
| belt 新增 3 个表面锚点 | 物块吸附带面中部（手操上带）| — |
| point_charge qm∈[−2,2] | 阴离子/负电荷题 | charge=qm·m 负值贯通 |
