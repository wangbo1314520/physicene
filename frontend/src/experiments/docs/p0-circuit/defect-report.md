# P0-2 缺陷报告：自由电路搭建引擎（CircuitEngine）从未交付

> 立项：2026-09-15 深夜 · 状态：**缺陷成立，进入修复** · 级别：P0（与已关闭的 P0-1“3D 动画静图”同级）
> 关联：B1 开工令《电路搭建自由度：自由拖元件搭电路，必须做》· 上线评审包 `b8-closure/launch-review.md`

## 一、缺陷声明

B1 开工令明确要求“自由拖拽电池、电阻、开关、电流表、电压表、滑动变阻器、电容器、电感器、二极管等；自由连线、节点连接、参数调节、电表量程选择、正负极性接反提示、短路/断路/接触不良检测、智能判分与错误定位”。

**实际交付：B1–B8 全程没有电路引擎。** 代码核实（2026-09-15）：`frontend/src` 中不存在任何求解器（无 MNA/节点电压法/netlist/相量分析），所有“circuit”命中均为 `defs/apparatus/circuit.ts` 绘图原语（电池/电阻/电表符号 + 电流点动画）的 import。电路类实验全部是**固定电路图 + 滑杆调参 + 读数 → 坐标纸**的模板式实现，学生无法放置元件、无法连线、无法接错、无法排错。

上线评审 55 卡逐卡 E2E 只验“能打开、能点、无报错”，没有“能搭电路”这一项，所以缺陷通过了评审。

## 四、根因

1. **DoD 缺项**：B1 验收单只列坐标纸 9 项，没有电路引擎条目；后续 B2–B8 各批次 DoD 都只覆盖本批新增。
2. **概念混淆**：“固定模板 + 调参数”（多用电表面板、RC 示波器、U–I 拟合）被当成了“自由搭建”。
3. **E2E 盲区**：只验可访问/可点击/无报错/提交成功；不验连线正确性、故障检测、判分。
4. **评审口径**：55 卡逐卡 E2E 验“能打开”，不验“能做核心操作”。
5. 与 P0-1（3D 静图）同一病根：**验收只看流程，不看教学本质**。

## 五、CircuitEngine 规格

目录：`frontend/src/experiments/circuit/`

### 5.1 数据模型（`types.ts`）
- `ComponentKind`：`battery | dc_source | ac_source | resistor | rheostat | switch | spdt_switch | ammeter | voltmeter | galvanometer | capacitor | inductor | diode | lamp | multimeter | oscilloscope | photoresistor | relay | wire_node`
- `CircuitComponent { id, kind, x, y, rot, pins: Pin[], props }`——`props` 含标称值、量程、极性、内阻（电表内阻真实存在：电压表 kΩ 级、电流表 Ω 级，用于“内接/外接法误差”）
- `Wire { id, a: PinRef, b: PinRef }`；`Netlist = { nodes, elements }` 由并查集合并被导线连接的引脚生成

### 5.2 求解器（`solver/`）
- `mna.ts` **直流 MNA**：电阻类（电阻/灯泡/滑动变阻器两段/电表内阻）、电压源（电池带内阻）、开关（闭合=微阻，断开=不参与）、二极管（分段线性 + 牛顿迭代 ≤ 20 次）；高斯消元带主元；奇异矩阵 → 判定“悬空节点/无回路”
- `transient.ts` **暂态**：后向欧拉伴随模型（C → 电导 C/Δt 并电流源；L → 电阻 Δt/L 串电压源），每步复用 MNA；覆盖 RC 充放电、RL 自感、LC 振荡（含电阻衰减）
- `ac.ts` **交流相量**：复数 MNA，Z_L=jωL、Z_C=1/(jωC)；输出各支路幅值/相位；覆盖 #6、#11 稀疏正弦源
- 灯泡亮度 = P/P_rated 映射到发光半径与色温；电表读数 = 量程 × 偏转（超量程 → 打表警告）

### 5.3 故障检测（`faults.ts`）
- **短路**：电源两端等效电阻 < 阈值（或支路电流 > 电源允许值）→ 高亮短路回路
- **断路**：开关闭合但目标支路电流为 0 / 节点不连通 → 高亮断点
- **电表错接**：电流表并联（→ 短路提示）、电压表串联（→ 读数≈电源、灯不亮）、极性反接（指针反打）
- **量程不当**：读数 < 1/3 量程 或 > 量程
- **接触不良**：导线可被标记为“虚接”，表现为间歇断路（用于排错任务）

### 5.4 判分与错误定位（`grading.ts`）
- 目标电路模板（netlist 拓扑 + 元件角色）与学生电路做**同构匹配**：按元件角色（电源/被测/表/控制）比对连接关系，输出“缺少/多余/错位”列表并映射到画布高亮
- 步骤判分钩子：`onNetlistChange → StepEngine`（B7 步骤条“操作仪器获取数据”按连线正确性放行；AI 助教读取 faults 给阶梯提示）
- 读数与理论值对比（物理正确性抽检）

### 5.5 编辑器（`editor/CircuitEditor.vue`）
- 左侧元件托盘（按实验清单白名单）→ 拖入画布（网格吸附、旋转、删除）
- 引脚吸附连线（正交折线、交叉跳线）；导线可选中删除；节点圆点
- 选中元件 → 参数面板（阻值/量程/极性/匝数…）；开关点击切换；滑动变阻器拖滑片
- 电表实时读数浮窗；灯泡亮度；电流点动画（复用 `apparatus/circuit.ts`）
- 与 `GraphPaper` 联动：`emit('record', {U, I, …})`；与 B6 持久化：netlist JSON 存 session 快照

### 5.6 交付形态
- 每个电路实验 = `CircuitEditor` + 本实验元件白名单 + 目标电路模板 + 任务脚本（步骤条）+ 坐标纸联动。旧的固定电路图组件退役或降级为“参考电路”缩略图。

## 七、验收制度整改（永久，写入 PROJECT-OVERVIEW 规则 12）

1. **元件清单对账**：每个实验必须有“应有元件 vs 实际元件”对账表，缺一不验。
2. **动画正确性 E2E**：多帧采样确认运动与参数响应（已落地：`exp-lib-check.py` `ANIMATED_IDS` 两帧必须不同，21 实验）。
3. **电路正确性 E2E**：连线、故障、判分必须实测（随 CircuitEngine 交付）。
4. **物理正确性抽检**：每个实验至少 1 项物理量对比理论值（误差阈值写入用例）。
5. **人工验收**：每批次人工逐实验操作，不得只靠自动化。
6. **截图/录屏归档**：每实验 ≥1 张运行截图 + 1 段动画录屏（`e2e/out/` + `snap-stage.py` 多帧）。
7. **教学本质检查**：每实验问一句“学生能不能做这个实验的核心操作”，不能只问“能不能打开”。
